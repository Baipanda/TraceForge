# Todo Show 使用指南

本文面向 Todo Show 的日常使用者，介绍如何查找、维护和同步 Todo。

## 1. 登录系统

1. 打开管理员提供的 Todo Show 地址。
2. 在“选择操作身份”窗口中选择自己的姓名。
3. 点击“进入系统”。

系统会使用所选身份记录创建、修改、填写进展、确认同步等操作。右上角会显示当前姓名；点击姓名旁的退出图标可以切换用户。

> 请务必选择自己的身份，避免操作日志记录到其他人名下。

## 2. 列表页

登录后默认进入 Todo 列表的树形视图。页面主要分为工作状态、同步安排、组合筛选和 Todo 表格四部分。

### 2.1 默认显示范围

系统默认开启“只看与我相关”，展示满足以下任一条件的 Todo：

- 当前用户属于主力人员；
- 当前用户属于流程管理人员。

关闭“只看与我相关”后，可以查看所有 Todo。手动选择“主力人员”或“流程管理人员”时，系统会关闭该默认范围，并按所选人员查询。

### 2.2 工作状态

- **待处理**：尚未完成的 Todo。
- **已完成**：已经完成的 Todo。
- **已取消**：不再继续执行的 Todo。

列表上方的状态按钮可以快速切换，筛选栏中的“工作状态”可以进行相同查询。

### 2.3 同步安排

同步安排位于列表上方：

| 筛选项 | 含义 |
|---|---|
| 当前需同步 | 当前应处理的同步事项，包括已逾期和今天到期的 Todo |
| 今日已填写 | 今天已经保存进展，但尚未确认同步 |
| 今日已同步 | 今天已经完成同步确认 |
| 已逾期 | 计划同步日期早于今天 |
| 今日到期 | 计划同步日期为今天 |
| 未来 7 天 | 从明天开始，未来 7 天内需要同步 |
| 未设置频率 | 尚未设置同步频率 |

选择同步安排后，工作状态会自动切换为“待处理”，并按照下一次同步时间排序。

### 2.4 其他筛选条件

可以组合使用以下条件：

- 优先级；
- 事项类型（Bug 或普通 Todo）；
- 分类；
- 父 Todo；
- 主力人员；
- 流程管理人员；
- 标题关键词；
- 排序方式。

优先级从高到低依次为：**高（High）**、**普通（Normal）**、**低（Low）**。

填写进展、确认同步或标记完成后，列表会保持当前 Todo 的相对顺序。只有主动修改排序条件、筛选条件或重新进入页面时，才会按照所选规则重新排列。

**搜索父 Todo：**在“父 Todo”输入框中输入标题，匹配项会显示在输入框下方。点击候选项，或按回车选择第一项。按 `Esc` 可以关闭候选列表。

### 2.5 表格字段

默认显示：标题、分类、优先级、主力人员、流程管理人员、同步状态、工作状态、状态提示和操作。Bug 会在标题前显示红色 `BUG` 标记。

点击右上角“列设置”，可以额外显示：

- 下一次同步时间；
- 同步频率；
- 创建时间；
- 父 Todo。

列设置会保存在当前浏览器中。

### 2.6 列表与树形视图

列表右上角可以切换两种展示方式：

- **列表**：按当前排序分页展示 Todo，适合快速扫描和批量处理。
- **树形**：按父子关系展示 Todo。点击标题左侧的箭头可以展开或收起子 Todo，子 Todo 会按层级缩进。

树形视图仍然遵循当前筛选条件。为了保留完整结构，系统会自动补充匹配 Todo 的父级路径；当匹配项本身是父 Todo 时，也会带出它的全部后代。因此部分上下文节点本身可能不符合当前筛选条件。

从树形列表进入 Todo 详情后，点击“返回”会恢复原来的展开层级和页面位置，并将刚才查看的 Todo 短暂高亮，方便继续处理相邻事项。该状态仅保存在当前浏览器标签页中，最多保留 30 分钟。

### 2.7 Bug 管理

创建或编辑 Todo 时，打开“标记为 Bug”开关即可将事项作为 Bug 管理。已有 Todo 默认都是普通 Todo；列表可以按事项类型筛选，详情页也会显示当前类型。

建议按以下方式使用现有字段：

- **标题**：简要描述故障现象；
- **描述**：记录复现步骤、预期结果、实际结果和影响范围；
- **优先级**：高表示阻塞或影响严重，普通表示一般功能问题，低表示轻微问题；
- **主力人员**：负责定位和修复；
- **流程管理人员**：负责跟踪、验证和关闭；
- **父 Todo**：关联出现问题的功能或交付事项；
- **进展记录**：持续记录定位结论、修复方案和验证结果。

Bug 继续使用 Todo 的工作状态。建议修复并验证通过后再标记为“已完成”；确认无需处理时使用“已取消”。

## 3. 填写与确认同步

同步分为两个步骤：先填写进展，再确认同步。

### 3.1 填写进展

1. 在“同步状态”列点击铅笔图标。
2. 阅读弹窗中的“填写提示”。该提示由 Todo 创建者设置。
3. 输入本次进展并点击“保存进展”。
4. 保存后，状态变为“今日已填写”。

填写进展只保存内容，不会推进下一次同步时间。此时 Todo 仍可能出现在“当前需同步”中。

点击同步状态旁的历史图标，可以快速查看该 Todo 最近 3 条同步记录，包括填写人、填写时间、确认状态和进展内容。

### 3.2 确认同步

1. 保存进展后，铅笔图标旁的圆形确认图标会变为可用。
2. 点击确认图标。
3. 状态变为“今日已同步”。
4. 系统根据同步频率计算新的下一次同步时间。

如果确认按钮不可点击，请先填写进展。已完成、已取消等结束状态的 Todo 无需继续同步。

### 3.3 同步状态说明

| 状态 | 含义 |
|---|---|
| 今日已填写 | 今天已保存进展，等待确认 |
| 待确认 | 之前已保存进展但仍未确认，且尚未超过原计划同步日期 |
| 待确认（已逾期） | 已保存进展但超过原计划同步日期仍未确认；使用红色提示 |
| 今日已同步 | 今天已确认同步 |
| 今日待同步 | 今天计划同步，尚未完成确认 |
| 已逾期 | 已超过计划同步日期 |
| 计划中 | 下一次同步日期在今天之后 |
| 未设置 | 未设置同步频率 |
| 已结束 | Todo 已完成、取消或过期，无需同步 |

> “同步确认”和“完成 Todo”是两个不同操作。同步确认表示本次进展已经确认；完成 Todo 表示整个事项已经结束。

### 3.4 父 Todo 自动同步

父 Todo 下只要还有“待处理”的子 Todo，就以这些子 Todo 作为当前有效子项。所有有效子 Todo 都在今天确认同步后，系统会自动为父 Todo 生成一条已确认的汇总记录，父 Todo 显示“今日已同步”，无需再次填写或确认。

如果之后有子 Todo 新增了未确认进展，或者子 Todo 的状态、层级发生变化，使汇总条件不再成立，系统汇总会失效，父 Todo 会恢复到实际同步状态。人工填写和人工确认的记录不会因此失效。

## 4. 完成 Todo

待处理 Todo 的“操作”列中会显示完成图标。点击后可将整个 Todo 标记为完成。

父 Todo 的所有直接子 Todo 都已经结束，并且子 Todo 占比合计为 `100%` 时，系统会自动将父 Todo 标记为已完成。这里“已经结束”包括：**已完成、已取消、已过期**，也就是子 Todo 中不再有“待处理”事项。该规则会逐级向上计算。

如果所有子 Todo 都已经结束，但占比合计不足 `100%`，剩余部分表示父 Todo 自身工作。完成剩余工作后，需要在列表中手动将父 Todo 标记为完成。仍有待处理子 Todo 时不能手动完成父 Todo。

系统自动完成的父 Todo 会在工作状态旁显示说明。如果之后新增或恢复了“待处理”子 Todo，父 Todo 会自动恢复为待处理；人工标记为完成的父 Todo 不会被自动恢复。若父 Todo 存在未完成依赖项，则会等依赖完成后再自动完成。

### 4.1 设置子 Todo 占比

进入父 Todo 详情页，在“子 Todo”表格中可以查看和修改每个直属子 Todo 的整数占比：

- 单项占比范围为 `0%～100%`，不支持小数；
- 所有子 Todo 占比合计不能超过 `100%`；
- 页面会实时显示子项合计和父 Todo 自身剩余占比；
- 修改多个占比后，统一点击“保存占比”；
- 新建或移动子 Todo 时，系统默认分配目标父 Todo 当前剩余占比。

已有 Todo 的子项占比已经按整数平均分配，余数按稳定顺序补齐，确保每个父 Todo 下合计为 `100%`。

如果 Todo 存在未完成的依赖项，系统会阻止完成并提示“存在未完成的依赖项”。请先完成依赖项，或在编辑页面中调整依赖关系。

## 5. 查看 Todo 详情

点击列表中的 Todo 标题进入详情页。详情页可以查看：

- 事项类型、描述、优先级、分类和项目；
- 主力人员、流程管理人员及其他角色；
- 父 Todo、子 Todo 和依赖项；
- 当前同步状态、同步频率和下一次同步时间；
- 完整的进展历史。

进展历史会显示填写人、填写时间、进展内容，以及是否确认、确认人和确认时间。父级自动同步记录会标记为“系统汇总”；条件变化后的旧汇总仍保留用于追溯，并标记为“已失效”，不会参与当前同步状态计算。

点击详情页的“编辑”可以修改 Todo 属性。修改后点击“保存修改”。

## 6. 创建 Todo

点击顶部导航中的“新建”，填写 Todo 信息。

### 必填内容

- 标题；
- 分类；
- 同步进展填写提示。

### 建议填写

- 描述和优先级；
- 如果事项是缺陷，打开“标记为 Bug”；
- 主力人员和流程管理人员；
- 同步频率；
- 项目、父 Todo 和依赖项。

同步频率支持：每天、每 3 天、每周、每两周和每月。未设置频率时，Todo 的同步状态显示为“未设置”。

“同步进展填写提示”会显示在填写进展弹窗中，应说明希望填写人汇报哪些内容，例如已完成工作、当前风险、下一步计划和预计时间。

人员多选时，Windows/Linux 按住 `Ctrl`，macOS 按住 `Command`，然后点击多个姓名。

## 7. 分类树与操作日志

### 分类树

点击顶部“分类树”，可以按分类层级浏览 Todo。点击分类可返回列表查看对应 Todo。

### 操作日志

点击顶部“日志”，可以查看系统中的操作记录，包括：

- 创建、更新、完成、取消和删除；
- 填写进展；
- 确认同步。
- 父项自动完成、自动恢复、自动同步和同步汇总失效。

日志可以按操作类型和用户名筛选。修改属性时，日志会记录修改了哪些字段以及修改前后的值。

## 8. 常见问题

### 登录后看不到预期的 Todo

先检查“只看与我相关”是否开启。关闭后可以查看全部 Todo；同时检查事项类型、工作状态、同步安排、分类、人员和标题等筛选条件。

### 保存进展后为什么仍在“当前需同步”中

保存进展后只是“今日已填写”，还需要点击旁边的确认图标。确认成功后才会推进下一次同步时间，并从当前待同步范围中移出。

### 确认按钮为什么是灰色

当前没有待确认的进展，或 Todo 已经结束。请先点击铅笔图标填写进展。

### 为什么无法完成 Todo

通常是因为存在未完成的依赖项。进入详情页查看“依赖项”，先处理依赖事项。

### 父 Todo 搜索没有结果

列表筛选只提供当前确实包含子 Todo 的父项。请确认输入的是父 Todo 标题，并尝试缩短关键词。

### 表格内容显示不全

表格支持横向滚动。也可以通过“列设置”关闭暂时不需要的可选列。

## 9. 推荐日常流程

1. 登录后保持“只看与我相关”。
2. 点击“当前需同步”，优先处理逾期和今天到期的 Todo。
3. 填写每个 Todo 的最新进展。
4. 检查内容无误后点击确认同步。
5. 对已经整体结束的事项，点击“操作”列中的完成图标。
6. 需要回顾时，在详情页查看进展历史，或在日志页查看操作记录。
